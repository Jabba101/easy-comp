AARDVARK EASY SUITE - getting the plugins onto your PC (Windows)
=================================================================

Right now this project makes:
    Easy Comp    a compressor (evens out the volume)
    Easy Trans   a transient shaper (more or less punch and ring on
                 every hit or note) - called Easy Transient up to 1.2.0
    Easy Gate    a gate (silences the noise and bleed between the
                 sounds you want)
    Easy DS      a de-esser (tames harsh S sounds, and harsh cymbals)
    Bitch-Slap   a gated reverb (the big 80s burst that stops dead)
    Easy Clip    a clipper (shaves the peaks so a track or a whole mix
                 can be louder)
    Easy Amp     a valve amp: from warmth to an overdriven rock growl
    Easy EQ      a four-band EQ with filters, mid-side and linear phase
    Easy Tape    a real tape machine: 15 ips, 30 ips, or cassette for lo-fi
    Easy Delay   a stereo delay (echo), in time with your song
    Easy Strip   all of the above in one channel strip (HOLOGRAM look)

Every time the project changes on GitHub, GitHub builds the plugins for you
on its own Windows computers. You just download and install them.


====================================================================
GETTING THE LATEST PLUGINS FROM GITHUB
====================================================================
 1. Go to your repository on github.com and click the "Actions" tab.

 2. Click the newest run with a green tick. (A yellow dot means it's
    still building. The first build after a big change takes about 40
    minutes; after that, most take a few minutes, because GitHub keeps
    copies of everything that didn't change.)

 3. Scroll down to "Artifacts" and click the download there. Its name
    ends with when it was built (year-month-day-time, UK time): e.g.
    "Aardvark-Easy-Suite-Windows-2026-10-21-1935" was built on 21
    October 2026 at 19:35. The zip in your Downloads folder keeps that
    name, so you can always tell which one is the newest.

 4. Before unzipping: right-click the downloaded file > Properties. If
    there's an "Unblock" tick-box at the bottom, tick it and click OK.
    (This stops Windows treating the plugins as untrusted downloads.)
    Then unzip it.

 5. Close your DAW (it keeps plugin files locked while it's open).

 6. Copy every ".vst3" folder from the download into:
       C:\Program Files\Common Files\VST3
    replacing the old ones. Windows will ask for administrator
    permission - click Continue.
    Updating from Easy Transient? It's now called Easy Trans, so also
    DELETE the old "Easy Transient.vst3" folder there. Otherwise your
    DAW finds two copies of the same plugin.

 7. Open your DAW and rescan your plugins. They're listed under
    "Aardvark Easy Suite" (it used to be "Home Studio"), in effects /
    dynamics - Bitch-Slap in effects / reverb, Easy Delay in effects /
    delay, Easy Amp and Easy Tape in effects / distortion, Easy EQ in
    effects / EQ.

 Your projects keep working: newer versions open older projects with
 any new features switched off, so they sound exactly as they did. That
 includes projects that used Easy Transient: your DAW recognises the
 plugin by a hidden code that never changes, so they open with Easy
 Trans and your settings.

 If a build shows a red cross:
    Click on the run, then on the job, copy the red error lines, and
    paste them to Claude.


====================================================================
BUILDING ON YOUR OWN PC INSTEAD (Visual Studio)
====================================================================
 Only needed if you'd rather not use GitHub.

 1. Install Visual Studio Community (free) from
    https://visualstudio.microsoft.com/downloads/ - when the installer
    asks, tick "Desktop development with C++". (Roughly 8-10 GB.)

 2. On your GitHub repository page, click the green "Code" button >
    "Download ZIP". Make a folder called Dev on your C: drive and
    extract the zip there, so you have e.g. C:\Dev\easy-comp-main with
    CMakeLists.txt directly inside it. (Avoid Documents: OneDrive and
    long paths cause trouble.)

 3. Start Visual Studio > "Open a local folder" > pick that folder.
    The configuration box at the top should say "Windows Release".
    Wait for "CMake generation finished" in the Output panel (the
    first time, it also downloads JUCE, so it needs internet).

 4. Build > Build All (Ctrl+Shift+B). When it says "Build succeeded",
    the plugins are in:
       C:\Dev\easy-comp-main\out\build\windows-release\Finished Plugins
    Install them as in steps 5-7 above.

 Build errors: View > Error List, copy the red lines, paste them to Claude.

YOUR FIRST FIVE MINUTES WITH EASY COMP
====================================================================
   1. Put it on a track and pick a preset for the instrument from the
      preset menu (top right). The help bar shows a tip for it.
   2. Play a loud section. Turn THRESHOLD down until the meter shows
      about what the tip suggests.
   3. Change ATTACK and listen to the start of each note or hit:
      slower = more punch, faster = softer.
   4. Change RELEASE and watch the meter: it should fall back between
      notes or hits, not stay down all the time.
   5. Switch AUTO-GAIN on, then click BYPASS on and off to compare.
      AUTO-GAIN keeps the volume the same either way, so you hear what
      the compression is doing rather than just "louder" (louder always
      sounds "better", which fools everyone's ears).
   6. On vocals, bass or a whole mix, try REACTS TO: AVERAGE for a
      smoother, more natural squeeze. On a mix or drum bus, if the kick
      makes everything "pump", turn up IGNORE BELOW (try 80-150 Hz).
   7. A / B (top, beside BYPASS): two sets of settings to compare while
      the track plays. B starts as a copy of A; COPY copies the one
      you're on to the other. Both are kept with your project.
   7. CHARACTER, for flavour:
        STYLE: MODERN     clean and precise - the knobs do exactly what
                          they say.
        STYLE: VINTAGE    our take on the classic "feedback" compressors
                          (in the zone of the API 2500's OLD setting): it
                          follows loud passages closely and eases back
                          gently when the sound drops away. Thicker, more
                          glue, less pumping - and it adds less distortion
                          to low notes than MODERN. Try it on the drum bus,
                          bass and the mix bus.
        LOW END: THRUST   the compressor hears less and less of the low
                          end the lower it goes (and a little more of the
                          bright, edgy range), so the kick and bass punch
                          through instead of setting it off. It only changes
                          what it reacts to, never your tone. You may need
                          THRESHOLD a little lower.
      Flick STYLE between MODERN and VINTAGE while the track plays
      (with AUTO-GAIN on): the amount of squeeze stays about the same,
      the feel changes.
   Hover over anything for a plain-English explanation.

   Found settings you like? Preset menu > "Save current settings as a
   preset...". Your presets are kept in Documents > Easy Plugins.

   The presets cover drums, bass, guitars, keys, vocals, strings, brass
   and wind, and the mix bus, with versions for different styles (for
   example "Vocal - Rock & Metal" or "Kick - Hip-Hop & R&B"), and VINTAGE
   and THRUST versions (e.g. "Drum Bus - Vintage Glue"). They're set up
   for tracks recorded at a normal level - the loudest peaks around -8 dB
   on your DAW's meter. If your track is much louder or quieter, the
   meter will show more or less than the tip says: just move THRESHOLD
   until it matches.

   The sidechain: with LISTENS TO set to SIDECHAIN, the compressor reacts
   to another track instead of your own - for example the kick turning
   the bass down a little on every hit ("ducking": the preset "Bass -
   Ducked by the Kick"), or music dipping under a voice. The presets
   under "Sidechain Tricks" say what to send. Your DAW does the routing,
   just like for Easy Gate. In Samplitude: in Easy Comp's plugin window,
   open the "Sidechain Input" menu at the top, switch on "Sidechain In"
   and pick the track to listen to (e.g. the kick). Then set LISTENS TO:
   SIDECHAIN. If the graph says NOTHING IS COMING INTO THE SIDECHAIN,
   the routing isn't connected yet.

   Updated from Easy Comp 1.5 and there's no "Sidechain Input" menu for
   Easy Comp in Samplitude? Samplitude remembers what each plugin could
   do when it last scanned it. Close Samplitude, then delete the file
   VSTPlugins.ini in C:\ProgramData\Boris FX\ (in the Samplitude folder
   for your version, e.g. Samplitude2026 - ProgramData is hidden, so
   paste the path into File Explorer's address bar). Start Samplitude
   and let it scan your plugins again. (If you'd added extra plugin
   folders under System options > Effects > VST/ReWire, add them again.)

YOUR FIRST FIVE MINUTES WITH EASY TRANS
====================================================================
   1. Put it on a drum track (or anything with clear hits or plucks)
      and pick a preset from the preset menu.
   2. Turn PUNCH up for a snappier start to each hit, or down to soften
      a harsh one. Watch the display: green shows where it got louder.
   3. Turn SUSTAIN down to shorten the ring and room after each hit
      (red in the display), or up to make the tail longer and bigger.
   4. Switch AUTO-GAIN on, then click BYPASS on and off to compare.
   5. Small amounts go a long way: if the hits start to sound clicky
      or the tails pumpy, back off, or lower MIX to blend in the
      original.
   Before or after Easy Comp? Either works, so try both. With Easy
   Transient first, the compressor then evens out what you shaped (more
   controlled). With Easy Trans last, its punch comes through
   untouched (punchier).

   The presets cover drums, bass, guitars, keys, vocals, strings, brass
   and the mix bus. Unlike the compressor's, they work the same however
   loud your track is.

YOUR FIRST FIVE MINUTES WITH EASY GATE
====================================================================
   1. Put it on a track with noise or bleed between the sounds you
      want - a tom or snare mic, a noisy guitar amp, a vocal - and
      pick a preset for it.
   2. Play the track and watch the display. The grey shape is what the
      gate hears; the dashed line is THRESHOLD. Move THRESHOLD so the
      hits (or notes, or words) go over the line and the bleed or noise
      between them stays under it. The red shading shows where it's
      turning the sound down.
   3. RANGE sets how much quieter it gets between hits. 15-25 dB
      sounds natural on drums; FULL is complete silence.
   4. HOLD and RELEASE set how it closes: longer lets each hit ring out,
      shorter is tighter. If tails get chopped off, make them longer.
   5. Bleed still opening it? Use IGNORE BELOW (e.g. the kick in a
      snare mic) or IGNORE ABOVE (e.g. cymbals in a tom mic). Click
      LISTEN to hear what the gate hears while you set them.
   6. Click BYPASS on and off to compare.

   It looks 2 ms ahead, so the start of every hit gets through. To do
   that it delays your track by 2 ms - your DAW makes up for it by
   itself ("delay compensation", on by default in every major DAW).

   The sidechain: with OPENED BY set to SIDECHAIN, another track opens
   the gate instead - for example the snare's close mic opening the
   room mics (the preset "Room Mics - 80s Gated Snare"). Every DAW does
   the routing differently: search your DAW's help for "sidechain". If
   the display says NOTHING IS COMING INTO THE SIDECHAIN, the routing
   isn't connected yet.

   The presets are set up for tracks recorded at a normal level (the
   loudest peaks around -8 dB on your DAW's meter): move THRESHOLD to
   suit yours.

YOUR FIRST FIVE MINUTES WITH EASY DS
====================================================================
   1. Put it on a vocal (or overheads, a hi-hat, a whole mix) and pick
      a preset for it.
   2. Play the track and watch the display. The grey shape is your
      sound and the amber line is the harsh band (where the S sounds
      are). The dashed line is THRESHOLD: it follows the rest of your
      sound up and down, so it works the same whether the singer is
      whispering or belting. Set THRESHOLD so the amber line goes over
      the dashed line on the S sounds only, not on ordinary words. The
      red shading and the meter show where it turns down.
   3. RANGE is the most it turns down. 3-6 dB sounds natural; much
      more and the S sounds start to lisp (sounding like "th").
   4. Not sure where the harshness is? Play the part with the most S
      sounds (or the harshest cymbals) and click FIND. It listens for 8
      seconds, then sets FROM and TO for you.
   5. Click LISTEN to hear only what it's taking out: you should hear
      just the S sounds, not the words.
   6. TURNS DOWN: HARSH BAND (the usual) dips only the harsh band, so
      the rest of your sound is untouched. WHOLE SOUND dips everything
      for the moment of each S - the classic, old-school style.
   7. Click BYPASS on and off to compare.

   Like Easy Gate, it looks 2 ms ahead (so it's already turned down as
   each S starts) and your DAW makes up for the 2 ms by itself.

   The presets cover vocals (male, female, rap, breathy, backing, very
   sibilant, the classic style, speech and podcasts), drums (overheads,
   hi-hat, room mics), acoustic guitar string squeaks and the mix bus.
   Unlike the compressor's, the vocal presets work the same however loud
   your track is.

YOUR FIRST FIVE MINUTES WITH BITCH-SLAP
====================================================================
   The 80s gated reverb: every hit - each snare, tom, ghost note, even
   the bleed - gets its own burst of big, wide reverb that stops dead.

   1. Put it on a snare or tom track and pick a preset, or play the
      track and turn up MIX. Up to 50% it only adds reverb (at 50% the
      burst is about as loud as the snare). Above 50% it also turns
      your original sound down, until 100% = reverb only.
   2. Set LENGTH: how long each burst lasts before it slams shut,
      counted from the hit. Short (100-200 ms) for fast songs, long
      (400-700 ms) for the huge 80s sound. Watch the display: each
      amber block is a burst, and it should end before the next snare
      hit. The bar in the display's top corner shows LENGTH on the
      same time scale.
   3. SYNC: TEMPO sets LENGTH as a note length instead (1/8, 1/4...),
      following your song's tempo - even when it changes. The line
      under SYNC shows what that works out to in milliseconds (with
      SYNC OFF, it shows how your LENGTH fits the song).
   4. Click BYPASS on and off to compare.

   Moving LENGTH never clicks or chops a burst: each hit keeps the
   burst it started with, and the new LENGTH starts with the next hits.

   As an FX send (the classic way - several drums sharing one reverb):
     In Samplitude: Track menu > Insert New Track > New AUX Bus. Put
     Bitch-Slap on the AUX bus as a track effect and pick a preset from
     "FX Send (Reverb Only)" (MIX 100%). Then use each drum track's
     AUX-Send slider in the mixer to send it to the bus; the bus's fader
     sets how much reverb you hear overall.

   On the mix bus: start from one of the "Mix Bus" presets. On a whole
   mix everything feeds the reverb at once, so it comes out far louder
   than on a single drum - MIX around 10-20% is plenty.

   Wide or mono: the burst is wide (different on the left and right).
   On a mono track, your DAW may give the plugin a mono output, and the
   burst is mono too. For the full width, use a send (above) or put it
   on a stereo track.

   It adds no delay to your track, and uses very little of your
   processor (about half a percent of one core, even with 1-second
   bursts) - nothing at all when bypassed, at MIX 0%, or in silence.

YOUR FIRST FIVE MINUTES WITH EASY CLIP
====================================================================
   A clipper shaves the tops off the loudest peaks - a snare's crack, a
   kick's attack - so the whole track (or mix) can be turned up without
   them poking out. Done gently you can't hear it; pushed hard it's a
   loud, aggressive crunch.

   1. Put it on a drum track, the drum bus or the master and pick a
      preset - or play the LOUDEST part of the song and turn PUSH up.
   2. Watch SHAVED OFF on the right: 1-3 dB on the loudest hits is
      usually unnoticeable (green). If it's regularly more, turn PUSH
      down - or the track down earlier in the chain - unless you want to
      hear the clipping.
   3. CEILING is the brick wall: nothing ever comes out louder. -1 dB
      is the safe choice on a finished song.
   4. SOFTNESS: 0% cuts the peaks flat (cleanest and loudest); turn it
      up for rounder, warmer peaks. PROTECT LOWS keeps the low boom of a
      kick or bass out of the clipper - set it just above the lowest
      note (80-120 Hz on a kick or a mix).
   5. Click BYPASS on and off to compare. The clipped version is
      louder, so compare at the same loudness (turn the track's fader
      down a little while Easy Clip is on) - louder always sounds
      "better" at first.

   ADVANCED (top left) shows SOUND DESIGN: TOP and BOTTOM clip each half
   of the wave at a different level, BIAS makes the rounding lopsided
   (both add grit and warmth), and BLEND mixes the original back in
   (parallel clipping). The lamp beside ADVANCED stays lit while any of
   these isn't neutral, so nothing hidden can surprise you; INIT in
   SOUND DESIGN puts just these back to neutral. LINK moves TOP and
   BOTTOM together, keeping the gap you set between them.

   OVERSAMPLING (top right): leave it on "4x / 8x" - 4x while you mix, 8x
   (the cleanest) when your DAW exports the song. OFF uses the least
   computer power but sounds harsher when you push hard. Easy Clip
   delays the sound by about 2 ms, the same whichever you choose, and
   tells your DAW so it lines everything up.

   Double-click a knob to reset it; double-click its number to type an
   exact value. The small red INIT beside the preset box puts every knob back to its
   default (the same as the "Default settings" preset).

YOUR FIRST FIVE MINUTES WITH EASY AMP
====================================================================
   An overdriven valve amp: the warm, rounded distortion of old valve
   (tube) gear rather than the harsh buzz of transistors. One knob takes
   it from clean to a growling rock sound - roughly from a warm DI bass
   to a cranked 70s/80s hard-rock amp (not high-gain metal).

   1. Put it on a bass, guitar, synth or drum track and pick a preset -
      or play the track and turn DRIVE up: a little for warmth, about
      halfway for a rough edge, all the way for a growl. The word under
      the curve tells you where you are (WARM, BREAKING UP, CRUNCH,
      GROWL).
   2. AUTO-GAIN starts ON here: as you turn DRIVE up, the volume stays
      the same, so you judge the tone, not the loudness. The number under
      the curve shows what it's doing.
   3. TONE: turn it down if the distortion sounds fizzy, up if it sounds
      dull. TIGHT keeps the low end out of the amp, clean - 80-120 Hz on
      bass and guitars stops distorted lows turning to mud.
   4. MIX below 100% blends your clean sound back in (parallel
      distortion) - great on drums and vocals.
   5. Click BYPASS on and off to compare.

   The curve in the middle shows what the amp does: straight = clean,
   bent = distorting, and flatter on one side = the valve's lopsided
   warmth. The two dots show where your track is playing right now.

   At DRIVE 0 it's switched off and costs nothing. OVERSAMPLING works
   like Easy Clip's (leave it on "4x / 8x"). The small red INIT beside the
   preset box puts every knob back to clean. Double-click a knob to
   reset it, or its number to type a value.


====================================================================
YOUR FIRST FIVE MINUTES WITH EASY TAPE
====================================================================
   A professional tape machine, recording and playing back: the subtle
   thing real tape does - a rounder, deeper low end and loud peaks that
   gently give - not the lo-fi caricature of a muffled top. (The
   worn-out cassette is there too, but only when you ask for it.)

   1. Put it on a track, a bus or the mix and pick a preset - or play
      the track and watch the VU meter while you turn DRIVE (the record
      level): around 0 VU is the subtle "it's on tape" sound; +3 to +6
      thickens and rounds the peaks; pinned in the red is hitting the
      tape hard, the way engineers did on drums. 0 dB means a track at
      -18 dBFS (RMS) hits the tape at its normal level.
   2. The volume stays put as you turn DRIVE (the playback level follows
      it the other way, and AUTO-GAIN trims the rest), so you hear the
      tape, not the loudness.
   3. SPEED:
        15 IPS     the multitrack machine and the default - the deep
                   head bump around 50 Hz, the highs softening only
                   when you push it.
        30 IPS     the mastering machine - almost perfect: a smaller
                   bump near 100 Hz, more headroom, the top barely
                   touched. A subtle touch.
        CASSETTE   lo-fi - less headroom, the highs squash early and
                   roll off.
      The curve under the meter shows the machine's response at that
      speed: within a couple of dB, as on a real machine.
   4. WOW & FLUTTER and HISS start at 0 - on a good studio machine
      they're barely there. Turn them up (with CASSETTE) for a worn,
      warbly lo-fi tape.
   5. Click BYPASS on and off to compare.

   OVERSAMPLING works like Easy Clip's (leave it on "4x / 8x"). The
   small red INIT beside the preset box goes back to 15 ips at the
   normal level. Double-click a knob to reset it, or its number to type
   a value.


====================================================================
YOUR FIRST FIVE MINUTES WITH EASY DELAY
====================================================================
   Echoes - from one quick slapback to dub-style repeats - in time with
   your song.

   1. Pick a preset, or set the time and turn MIX up: 15-30% is usual on
      a track. (On an FX send, use the "Send -" presets: echoes only.)
   2. WHEN: SYNC on TEMPO sets TIME as a note (1/8, dotted 1/8, 1/4...)
      that follows your song's tempo; OFF sets it in milliseconds (under
      about 120 ms = slapback). The line underneath says what it comes to.
   3. REPEATS: FEEDBACK is how many echoes (0 = just one). MODE: STEREO,
      PING-PONG (the echoes bounce left and right) or WIDE (the right
      side's echoes half as late again - 1/8 left, dotted 1/8 right).
   4. TONE: LOW CUT and HIGH CUT thin and darken the echoes - a little
      more with every repeat, like a vintage echo unit - so they sit
      behind your sound. CHARACTER: CLEAN (every repeat exact) or TAPE
      (a tape echo: warmer, a slight wobble, and moving TIME bends the
      pitch).
   5. OUTPUT: DUCK turns the echoes down while you play or sing and lets
      them come up in the gaps - the trick for clear vocals with echoes.

   The picture shows your sound and the echoes after it (left above the
   line, right below), each as loud as it will be. No delay is added to
   the track itself. The small red INIT beside the preset box goes back
   to the defaults.


====================================================================
YOUR FIRST FIVE MINUTES WITH EASY EQ
====================================================================
   Four bands - LOW, LOW MID, HIGH MID, HIGH - plus filters, drawn on a
   big screen over a faint picture of your sound.

   1. Pick a preset, or drag a band's coloured dot on the screen: across
      for the frequency, up or down for boost or cut. Double-click a dot
      to put it back to 0 dB. The knobs underneath do the same.
   2. Not sure where a problem is? Hold a band's LISTEN button: you hear
      only what that band covers. Move its FREQ while you hold it until
      the boom, mud, honk or harshness is loudest - then let go and cut
      it there. (The frequency guide at the bottom helps too.)
   3. There's no "width" knob: the harder you boost or cut, the narrower
      a band gets by itself. Small moves stay broad and musical.
   4. CLEAN UP: HPF removes rumble below its frequency (60-120 Hz on
      almost everything except kick and bass), LPF removes fizz and hiss
      above it. 12 or 24 sets how steeply. MONO BASS keeps the lows of a
      stereo track in the middle (try 80-120 Hz on the mix bus).
   5. ST / MID / SIDE under each band: work on the whole sound, only the
      middle (vocal, kick, snare, bass) or only the sides (room, width,
      stereo guitars). The screen then draws MID in cyan and SIDE in
      magenta.

   AUTO-GAIN starts off here: how the level moves as you EQ is part of
   the sound. Switch it on to check whether a boost really sounds better,
   not just louder.

   MASTER (top right): linear phase, for a drum bus or a finished mix -
   keeps the timing of every frequency perfectly intact. It adds a delay
   of about 43 ms (Samplitude lines everything up for it) and uses more
   computer power, so don't use it while recording. Switching it on or
   off changes the delay, so Samplitude may take a moment to re-align.

   PRECISION (LOW / MED / HIGH, beside MASTER): HIGH is the most exact
   low end (about 43 ms of delay). MEDIUM halves the delay; LOW quarters
   it and leaves less faint smear just before each hit (good on drums),
   but bands below about 60 Hz come out a little broader.

   A / B (top middle): two sets of settings to compare - switch between
   them while the track plays. B starts as a copy of A; COPY copies the
   one you're on to the other. Both are kept with your project.

   ANALYSER (top left) switches the picture of your sound on and off.
   The small red INIT beside the preset box puts everything back flat.
   Double-click a knob to reset it, or its number to type a value.

YOUR FIRST FIVE MINUTES WITH EASY STRIP
====================================================================
   Every Easy plugin in one channel strip, in this order:
      INPUT > TAPE > GATE > AMP > EQ > DS > COMP > TRANS > DELAY > BITCH-SLAP > CLIP > OUTPUT

   TAPE comes first: as if the track had been recorded to tape and you're
   mixing from the machine (the most natural-sounding place; ORDER can
   move it to the end). Its panel is in the right-hand column, under
   TRANS.

   Each module IS its plugin: the same sound (tested sample for sample),
   the same controls, numbered sections, presets and help text. Your own
   saved presets are shared with the standalone plugins.

   The HOLOGRAM look (the default) puts every module on one panel:
   1. Every module starts switched off. Click a module's name button (the
      big one at the top of its panel) to switch it on - lit = on. Off,
      it isn't run at all and costs nothing, and the strip's timing never
      changes when you switch.
   2. Each module has its own INIT (red: just that module back to its
      defaults) and Pr (that module's presets - load or save).
   3. The big screen shows ONE module: press its DISPLAY FOCUS button
      (the row just above the screen). On the EQ page, drag the
      numbered dots.
   4. Every control: drag up or down (Shift for fine), or use the mouse
      wheel. Double-click the control to reset it; double-click its
      NUMBER to type a value (10 on a frequency means 10 kHz where that
      fits; "off" works where there's an OFF).
   5. The ticker along the bottom explains whatever the mouse is over,
      and shows the exact value while you turn something.
   6. INPUT (left): TRIM, the polarity flip, the meter. OUTPUT (right):
      AUTO GAIN for the whole strip (keeps the output as loud as what
      comes in, so BYPASS compares the sound, not the volume; the number
      under it shows what it's doing; with CLIP on it only turns down),
      PEAK / LUFS meter, LUFS S (last 3 seconds) and I (whole song -
      click it to start again), LEVEL.
   7. Header: the strip's presets (arrows step through them - about 80
      of them, by instrument: each switches on the modules it needs, each
      with one of that module's own presets; the ticker shows its tip),
      A / B / COPY (two versions of the whole strip to compare), one
      OVERSAMPLING for AMP, TAPE and CLIP, INIT (the whole strip), BYPASS (the
      whole strip), SETUP. Comp and the EQ also have their own A / B.
   8. Clip's ADVANCED shows its SOUND DESIGN row under the EQ.
   9. ORDER (header, by A / B; also in SETUP): five switches for the
      order the sound goes through - EQ AFTER COMP, DE-ESS BEFORE DRIVE,
      DRIVE AFTER COMP, SHAPE BEFORE COMP, and TAPE AT THE END (tape
      just before CLIP instead of first: like mixing down to a master
      machine - for buses, mastering and creative use). The panels never
      move; the menu (and the ticker, hovering ORDER) shows the order,
      and the button lights while it isn't the standard one. Switching
      while playing dips the sound for a moment (no clicks). DELAY,
      BITCH-SLAP and CLIP are always last (DELAY before BITCH-SLAP, so the
      gated reverb catches the echoes). Presets and A / B include the order.
   10. WEAPON SELECT (the striped button under TAPE) opens the effects
      rack in place of GATE, AMP, the big screen, EQ, DS and COMP - they
      keep working, they're just out of sight. TRANS, TAPE, CLIP, INPUT
      / OUTPUT and the header stay. DELAY (bay 5) and BITCH-SLAP (bay 6)
      live in the rack; the other bays are where the auto-wah, chorus /
      flanger, mod filter, tremolo and limiter will go. Press WEAPON
      SELECT again to go back.
   11. The sidechain input goes to both GATE and COMP (each one's
      OPENED BY / LISTENS TO decides whether it uses it).

   SETUP (top right): window size (60% to 150%, or drag the window's
   corner), the skin (HOLOGRAM, or CLASSIC - which shows each module's
   own standalone window), the ticker on or off, what 0 means on the
   INPUT / OUTPUT meters (0 dBFS, or -18 dBFS like a VU meter) and
   DISPLAY BRIGHTNESS. These are remembered for every Easy Strip.
   Also in SETUP, for this strip only: EQ MASTER PRECISION (see Easy EQ).

   In Samplitude every module's settings show up as "Comp Threshold",
   "Gate Range" and so on, so automation works on all of them.

CHANGING THINGS
====================================================================
   - Built-in presets: Presets.h in each plugin's folder (e.g.
                       Plugins\EasyComp\Presets.h) - one line each.
   - Colours:          the Palette list at the top of Shared\Look.h.
   - Help text:        the knobInfo list in each plugin's PluginEditor.cpp.
   - The sound:        Effects\Compressor.h, Effects\TransientShaper.h,
                       Effects\Gate.h, Effects\DeEsser.h and
                       Effects\GatedReverb.h - commented step by step.
