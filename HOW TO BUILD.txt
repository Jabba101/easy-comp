AARDVARK EASY SUITE - getting the plugins onto your PC (Windows)
=================================================================

Right now this project makes:
    Easy Comp    a compressor (evens out the volume)
    Easy Trans   a transient shaper (more or less punch and ring on
                 every hit or note) - called Easy Transient up to 1.2.0
    Easy Gate    a gate (silences the noise and bleed between the
                 sounds you want)
    Easy DS      a de-esser (tames harsh S sounds, and harsh cymbals)

Every time the project changes on GitHub, GitHub builds the plugins for you
on its own Windows computers. You just download and install them.


====================================================================
GETTING THE LATEST PLUGINS FROM GITHUB
====================================================================
 1. Go to your repository on github.com and click the "Actions" tab.

 2. Click the newest run with a green tick. (A yellow dot means it's
    still building - it takes about 10 minutes.)

 3. Scroll down to "Artifacts" and click "Aardvark-Easy-Suite-Windows"
    to download it.

 4. Before unzipping: right-click the downloaded file > Properties. If
    there's an "Unblock" tick-box at the bottom, tick it and click OK.
    (This stops Windows treating the plugins as untrusted downloads.)
    Then unzip it.

 5. Close your DAW (it keeps plugin files locked while it's open).

 6. Copy every ".vst3" folder from the download into:
       C:\Program Files\Common Files\VST3
    replacing the old ones. Windows will ask for administrator
    permission - click Continue.
    Updating from Easy Transient? It's now called Easy Trans, so also
    DELETE the old "Easy Transient.vst3" folder there. Otherwise your
    DAW finds two copies of the same plugin.

 7. Open your DAW and rescan your plugins. They're listed under
    "Aardvark Easy Suite" (it used to be "Home Studio"), in effects /
    dynamics.

 Your projects keep working: newer versions open older projects with
 any new features switched off, so they sound exactly as they did. That
 includes projects that used Easy Transient: your DAW recognises the
 plugin by a hidden code that never changes, so they open with Easy
 Trans and your settings.

 If a build shows a red cross:
    Click on the run, then on the job, copy the red error lines, and
    paste them to Claude.


====================================================================
BUILDING ON YOUR OWN PC INSTEAD (Visual Studio)
====================================================================
 Only needed if you'd rather not use GitHub.

 1. Install Visual Studio Community (free) from
    https://visualstudio.microsoft.com/downloads/ - when the installer
    asks, tick "Desktop development with C++". (Roughly 8-10 GB.)

 2. On your GitHub repository page, click the green "Code" button >
    "Download ZIP". Make a folder called Dev on your C: drive and
    extract the zip there, so you have e.g. C:\Dev\easy-comp-main with
    CMakeLists.txt directly inside it. (Avoid Documents: OneDrive and
    long paths cause trouble.)

 3. Start Visual Studio > "Open a local folder" > pick that folder.
    The configuration box at the top should say "Windows Release".
    Wait for "CMake generation finished" in the Output panel (the
    first time, it also downloads JUCE, so it needs internet).

 4. Build > Build All (Ctrl+Shift+B). When it says "Build succeeded",
    the plugins are in:
       C:\Dev\easy-comp-main\out\build\windows-release\Finished Plugins
    Install them as in steps 5-7 above.

 Build errors: View > Error List, copy the red lines, paste them to Claude.

YOUR FIRST FIVE MINUTES WITH EASY COMP
====================================================================
   1. Put it on a track and pick a preset for the instrument from the
      preset menu (top right). The help bar shows a tip for it.
   2. Play a loud section. Turn THRESHOLD down until the meter shows
      about what the tip suggests.
   3. Change ATTACK and listen to the start of each note or hit:
      slower = more punch, faster = softer.
   4. Change RELEASE and watch the meter: it should fall back between
      notes or hits, not stay down all the time.
   5. Switch AUTO-GAIN on, then click BYPASS on and off to compare.
      AUTO-GAIN keeps the volume the same either way, so you hear what
      the compression is doing rather than just "louder" (louder always
      sounds "better", which fools everyone's ears).
   6. On vocals, bass or a whole mix, try REACTS TO: AVERAGE for a
      smoother, more natural squeeze. On a mix or drum bus, if the kick
      makes everything "pump", turn up IGNORE BELOW (try 80-150 Hz).
   7. CHARACTER, for flavour:
        STYLE: MODERN     clean and precise - the knobs do exactly what
                          they say.
        STYLE: VINTAGE    our take on the classic "feedback" compressors
                          (in the zone of the API 2500's OLD setting): it
                          follows loud passages closely and eases back
                          gently when the sound drops away. Thicker, more
                          glue, less pumping - and it adds less distortion
                          to low notes than MODERN. Try it on the drum bus,
                          bass and the mix bus.
        LOW END: THRUST   the compressor hears less and less of the low
                          end the lower it goes (and a little more of the
                          bright, edgy range), so the kick and bass punch
                          through instead of setting it off. It only changes
                          what it reacts to, never your tone. You may need
                          THRESHOLD a little lower.
      Flick STYLE between MODERN and VINTAGE while the track plays
      (with AUTO-GAIN on): the amount of squeeze stays about the same,
      the feel changes.
   Hover over anything for a plain-English explanation.

   Found settings you like? Preset menu > "Save current settings as a
   preset...". Your presets are kept in Documents > Easy Plugins.

   The presets cover drums, bass, guitars, keys, vocals, strings, brass
   and wind, and the mix bus, with versions for different styles (for
   example "Vocal - Rock & Metal" or "Kick - Hip-Hop & R&B"), and VINTAGE
   and THRUST versions (e.g. "Drum Bus - Vintage Glue"). They're set up
   for tracks recorded at a normal level - the loudest peaks around -8 dB
   on your DAW's meter. If your track is much louder or quieter, the
   meter will show more or less than the tip says: just move THRESHOLD
   until it matches.

   The sidechain: with LISTENS TO set to SIDECHAIN, the compressor reacts
   to another track instead of your own - for example the kick turning
   the bass down a little on every hit ("ducking": the preset "Bass -
   Ducked by the Kick"), or music dipping under a voice. The presets
   under "Sidechain Tricks" say what to send. Your DAW does the routing,
   just like for Easy Gate. In Samplitude: in Easy Comp's plugin window,
   open the "Sidechain Input" menu at the top, switch on "Sidechain In"
   and pick the track to listen to (e.g. the kick). Then set LISTENS TO:
   SIDECHAIN. If the graph says NOTHING IS COMING INTO THE SIDECHAIN,
   the routing isn't connected yet.

   Updated from Easy Comp 1.5 and there's no "Sidechain Input" menu for
   Easy Comp in Samplitude? Samplitude remembers what each plugin could
   do when it last scanned it. Close Samplitude, then delete the file
   VSTPlugins.ini in C:\ProgramData\Boris FX\ (in the Samplitude folder
   for your version, e.g. Samplitude2026 - ProgramData is hidden, so
   paste the path into File Explorer's address bar). Start Samplitude
   and let it scan your plugins again. (If you'd added extra plugin
   folders under System options > Effects > VST/ReWire, add them again.)

YOUR FIRST FIVE MINUTES WITH EASY TRANS
====================================================================
   1. Put it on a drum track (or anything with clear hits or plucks)
      and pick a preset from the preset menu.
   2. Turn PUNCH up for a snappier start to each hit, or down to soften
      a harsh one. Watch the display: green shows where it got louder.
   3. Turn SUSTAIN down to shorten the ring and room after each hit
      (red in the display), or up to make the tail longer and bigger.
   4. Switch AUTO-GAIN on, then click BYPASS on and off to compare.
   5. Small amounts go a long way: if the hits start to sound clicky
      or the tails pumpy, back off, or lower MIX to blend in the
      original.
   Before or after Easy Comp? Either works, so try both. With Easy
   Transient first, the compressor then evens out what you shaped (more
   controlled). With Easy Trans last, its punch comes through
   untouched (punchier).

   The presets cover drums, bass, guitars, keys, vocals, strings, brass
   and the mix bus. Unlike the compressor's, they work the same however
   loud your track is.


====================================================================
YOUR FIRST FIVE MINUTES WITH EASY GATE
====================================================================
   1. Put it on a track with noise or bleed between the sounds you
      want - a tom or snare mic, a noisy guitar amp, a vocal - and
      pick a preset for it.
   2. Play the track and watch the display. The grey shape is what the
      gate hears; the dashed line is THRESHOLD. Move THRESHOLD so the
      hits (or notes, or words) go over the line and the bleed or noise
      between them stays under it. The red shading shows where it's
      turning the sound down.
   3. RANGE sets how much quieter it gets between hits. 15-25 dB
      sounds natural on drums; FULL is complete silence.
   4. HOLD and RELEASE set how it closes: longer lets each hit ring out,
      shorter is tighter. If tails get chopped off, make them longer.
   5. Bleed still opening it? Use IGNORE BELOW (e.g. the kick in a
      snare mic) or IGNORE ABOVE (e.g. cymbals in a tom mic). Click
      LISTEN to hear what the gate hears while you set them.
   6. Click BYPASS on and off to compare.

   It looks 2 ms ahead, so the start of every hit gets through. To do
   that it delays your track by 2 ms - your DAW makes up for it by
   itself ("delay compensation", on by default in every major DAW).

   The sidechain: with OPENED BY set to SIDECHAIN, another track opens
   the gate instead - for example the snare's close mic opening the
   room mics (the preset "Room Mics - 80s Gated Snare"). Every DAW does
   the routing differently: search your DAW's help for "sidechain". If
   the display says NOTHING IS COMING INTO THE SIDECHAIN, the routing
   isn't connected yet.

   The presets are set up for tracks recorded at a normal level (the
   loudest peaks around -8 dB on your DAW's meter): move THRESHOLD to
   suit yours.


====================================================================
YOUR FIRST FIVE MINUTES WITH EASY DS
====================================================================
   1. Put it on a vocal (or overheads, a hi-hat, a whole mix) and pick
      a preset for it.
   2. Play the track and watch the display. The grey shape is your
      sound and the amber line is the harsh band (where the S sounds
      are). The dashed line is THRESHOLD: it follows the rest of your
      sound up and down, so it works the same whether the singer is
      whispering or belting. Set THRESHOLD so the amber line goes over
      the dashed line on the S sounds only, not on ordinary words. The
      red shading and the meter show where it turns down.
   3. RANGE is the most it turns down. 3-6 dB sounds natural; much
      more and the S sounds start to lisp (sounding like "th").
   4. Not sure where the harshness is? Play the part with the most S
      sounds (or the harshest cymbals) and click FIND. It listens for 8
      seconds, then sets FROM and TO for you.
   5. Click LISTEN to hear only what it's taking out: you should hear
      just the S sounds, not the words.
   6. TURNS DOWN: HARSH BAND (the usual) dips only the harsh band, so
      the rest of your sound is untouched. WHOLE SOUND dips everything
      for the moment of each S - the classic, old-school style.
   7. Click BYPASS on and off to compare.

   Like Easy Gate, it looks 2 ms ahead (so it's already turned down as
   each S starts) and your DAW makes up for the 2 ms by itself.

   The presets cover vocals (male, female, rap, breathy, backing, very
   sibilant, the classic style, speech and podcasts), drums (overheads,
   hi-hat, room mics), acoustic guitar string squeaks and the mix bus.
   Unlike the compressor's, the vocal presets work the same however loud
   your track is.


====================================================================
CHANGING THINGS
====================================================================
   - Built-in presets: Presets.h in each plugin's folder (e.g.
                       Plugins\EasyComp\Presets.h) - one line each.
   - Colours:          the Palette list at the top of Shared\Look.h.
   - Help text:        the knobInfo list in each plugin's PluginEditor.cpp.
   - The sound:        Effects\Compressor.h, Effects\TransientShaper.h,
                       Effects\Gate.h and Effects\DeEsser.h - commented
                       step by step.


====================================================================
WHAT'S IN THIS FOLDER
====================================================================
   PLAN.txt               What's planned next, and in what order.
   DevTools\              The testing and preset-tuning tools - not part of
                          the plugins, kept so that work is never lost (see
                          DevTools\README.txt).
   CMakeLists.txt         The build recipe (downloads JUCE automatically).
   CMakePresets.json      Tells Visual Studio to make an optimised build.
   .github\workflows\     The instructions GitHub follows to build them.

   Effects\               The sound-shaping code (no windows or knobs):
     Compressor.h           the compressor
     TransientShaper.h      the transient shaper
     Gate.h                 the gate
     DeEsser.h              the de-esser
     HarshnessFinder.h      Easy DS's FIND button
     LoudnessMatcher.h      AUTO-GAIN (shared by every plugin)
     FastMath.h             quick decibel maths and helpers for working on
                            several samples at once (shared by every plugin)

   Shared\                The parts every plugin shares: the look, the
                          help bar, BYPASS / AUTO-GAIN, the preset menu,
                          saving with your projects.

   Plugins\EasyComp\      Easy Comp's knobs, window and presets.
   Plugins\EasyTransient\ Easy Trans's knobs, window and presets (the
                          folder keeps the old name).
   Plugins\EasyGate\      Easy Gate's knobs, window and presets.
   Plugins\EasyDS\        Easy DS's knobs, window and presets.

   On a Mac, the same folder builds VST3 and AU versions (needs Xcode and
   CMake: run "cmake --preset release" then "cmake --build --preset release").
