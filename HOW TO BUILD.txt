EASY COMP - turning this folder into a plugin you can use (Windows)
====================================================================

There are two ways to build the plugin. Pick one:

  OPTION 1 - Let GitHub build it for you. Nothing to install.
             About 15 minutes, mostly waiting.
  OPTION 2 - Build it on your own PC with Visual Studio (free, but an
             8-10 GB install). About 30-60 minutes the first time.

Both make exactly the same plugin. Neither involves typing commands.


====================================================================
OPTION 1: LET GITHUB BUILD IT FOR YOU
====================================================================
GitHub can build the plugin on its own Windows computers. This is free:
a private repository gets 2,000 free build minutes a month, and one
build takes roughly 10.

 1. Unzip EasyComp.zip anywhere (your Downloads folder is fine).

 2. On github.com, click the "+" at the top right > "New repository".
    Name it  easy-comp , choose "Private", and click "Create repository".

 3. On the page that appears, click the link "uploading an existing file".

 4. In File Explorer, open the EasyComp folder, press Ctrl+A to select
    everything inside it (including the .github folder), and drag it all
    onto the GitHub page. When the files are listed, click
    "Commit changes".

 5. Check that the file list on your repository's main page includes a
    .github folder. (If it doesn't, see "If the .github folder is
    missing" below.)

 6. Click the "Actions" tab. "Build Easy Comp" will be running (yellow
    dot). After about 10 minutes it turns into a green tick.

 7. Click on that run, scroll down to "Artifacts", and click
    "Easy-Comp-Windows" to download it.

 8. Before unzipping: right-click the downloaded file > Properties. If
    there's an "Unblock" tick-box at the bottom, tick it and click OK.
    (This stops Windows treating the plugin as an untrusted download.)
    Then unzip it and copy the "Easy Comp.vst3" folder into:
       C:\Program Files\Common Files\VST3
    Windows will ask for administrator permission - click Continue.

 9. Open your DAW and rescan your plugins. It appears as "Easy Comp"
    by "Home Studio", under effects / dynamics.

 If the .github folder is missing after uploading:
    Actions tab > "set up a workflow yourself" > delete the example text >
    open EasyComp\.github\workflows\build.yml in Notepad, copy all of it,
    paste it in > "Commit changes". The build then starts by itself.

 If the build shows a red cross:
    Click on the run, then on "Windows VST3", copy the red error lines,
    and paste them to Claude.

 Changing the plugin later:
    Upload the changed files to the repository again (same as step 3-4,
    GitHub replaces the old ones). It rebuilds by itself. Download the
    new artifact, close your DAW, and copy the new "Easy Comp.vst3" over
    the old one.


====================================================================
OPTION 2: BUILD IT ON YOUR PC WITH VISUAL STUDIO
====================================================================

1. INSTALL VISUAL STUDIO (free)
   - Go to https://visualstudio.microsoft.com/downloads/ and download
     "Visual Studio Community" (the free edition).
   - Run the installer. When it asks what you want to install, tick
     "Desktop development with C++" and click Install.
     (Roughly 8-10 GB. Leave the options inside that box as they are.)
   - Restart your PC if it asks you to.

2. PUT THIS FOLDER SOMEWHERE SIMPLE
   - Make a folder called Dev on your C: drive.
   - Right-click EasyComp.zip > "Extract All...", choose C:\Dev as the
     destination, and click Extract.
   - You should now have C:\Dev\EasyComp, with CMakeLists.txt directly
     inside it.
   Why not Documents? It's often synced by OneDrive (which would try to
   upload thousands of build files) and its long path can trip Windows'
   260-character path limit.

3. OPEN IT IN VISUAL STUDIO
   - Start Visual Studio and choose "Open a local folder" on the start
     screen (or File > Open > Folder...). Select C:\Dev\EasyComp.
   - In the toolbar at the top, the configuration box should say
     "Windows Release". If it doesn't, pick that from the drop-down.
   - Visual Studio now sets up the project. The first time, it also
     downloads JUCE (the free audio framework the plugin is built on),
     so it needs internet and a few minutes. It's ready when the Output
     panel at the bottom says:  CMake generation finished.

4. BUILD IT
   - Menu: Build > Build All   (or press Ctrl+Shift+B).
   - The first build takes a few minutes. When it's done, the Output
     panel says "Build All succeeded" (or "Build succeeded").

5. INSTALL THE PLUGIN
   - In File Explorer, go to:
       C:\Dev\EasyComp\out\build\windows-release\EasyComp_artefacts\Release\VST3
   - Copy "Easy Comp.vst3" from there into:
       C:\Program Files\Common Files\VST3
     Windows will ask for administrator permission - click Continue.
     ("Easy Comp.vst3" is a folder on Windows. That's normal - copy the
     whole thing.)
   - Open your DAW and rescan your plugins. It appears as "Easy Comp"
     by "Home Studio", under effects / dynamics.

 If something goes wrong:
   - Build errors: open View > Error List, copy the red lines, and paste
     them to Claude. Most problems are a quick fix.

 Changing the plugin later:
   After editing a file: Build > Build All again, close your DAW, and
   copy the new "Easy Comp.vst3" over the old one.


====================================================================
YOUR FIRST FIVE MINUTES WITH IT
====================================================================
   1. Put it on a snare track and pick "Snare - Crack" from the preset menu.
   2. Play a loud section. Turn THRESHOLD down until the meter jumps about
      3-6 dB on each hit.
   3. Change ATTACK and listen to the start of each hit: slower = more
      "crack", faster = softer.
   4. Change RELEASE and watch the meter: try to have it drop back near
      zero just before the next hit.
   5. Use MAKE-UP so it's the same loudness with the plugin on and off
      (use your DAW's bypass button to compare). Louder always sounds
      "better", so match levels before you judge.
   6. On a drum bus, if every kick drum makes the whole kit duck and
      "pump", turn up IGNORE BELOW (try 80-150 Hz) so the kick stops
      setting it off.
   Watch the COMPRESSION CURVE as you turn THRESHOLD and RATIO: the bend
   moves with THRESHOLD, and the line flattens as RATIO goes up.
   Hover over any control for a plain-English explanation.


====================================================================
IF YOUR DAW DOESN'T SHOW THE PLUGIN
====================================================================
   - Check that your DAW scans C:\Program Files\Common Files\VST3, and
     that you copied the whole "Easy Comp.vst3" folder.
   - Windows won't let you replace the plugin? Close your DAW first -
     DAWs keep the plugin file open while they're running.


====================================================================
CHANGING THINGS
====================================================================
   - Presets:   Source\Presets.h - one line per preset.
   - Colours:   the Palette list at the top of Source\PluginEditor.h.
   - Help text: the knobInfo list near the top of Source\PluginEditor.cpp.
   - The sound: Source\Compressor.h - commented step by step.


====================================================================
WHAT'S IN THIS FOLDER
====================================================================
   CMakeLists.txt            The build recipe (downloads JUCE automatically).
   CMakePresets.json         Tells Visual Studio to make an optimised build.
   .github\workflows\build.yml
                             The instructions GitHub follows to build it.
   Source\Compressor.h       The sound: detector (with IGNORE BELOW),
                             threshold/ratio curve, attack/release, make-up
                             and mix.
   Source\Presets.h          The drum presets and parameter names.
   Source\PluginProcessor.*  Connects the compressor to your DAW: knobs,
                             automation, saving with your project.
   Source\PluginEditor.*     The window: knobs, curve graph, meter, preset
                             menu, help bar.

   On a Mac, the same folder builds VST3 and AU versions (needs Xcode and
   CMake: run "cmake --preset release" then "cmake --build --preset release").
